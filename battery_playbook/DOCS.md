# Battery Playbook

This app writes three Home Assistant packages for a Solis S6-EH1P with a home
battery on a Flemish (Fluvius) connection, filled in with your own entities and
settings:

| Package | What it does | After install |
| --- | --- | --- |
| Peak shaving | Charges the battery overnight while keeping grid import under the limit, tracks quarter-hour peaks, learns how much your trees shade the forecast | Off until you switch on **Peak shaving enabled** |
| Dynamic-tariff rules | Plans charge, export or self-use every hour on Eneco Dynamisch prices | Shadow mode: off until you switch on **Dynamic tariff control** |
| Contract watch | Prices your real usage on both contracts, sends monthly and renewal alerts | Runs straight away |

The app runs once and stops. Change a setting, press **Start** again, and it
rewrites what changed, checks the configuration and restarts Home Assistant.

## Before you start

You need these integrations first. The app finds their entities by itself.

1. **Solis Modbus** (HACS) with a working local connection to the inverter.
2. **Forecast.Solar** for your roof (no damping).
3. **ENTSO-e** (HACS) with your API token, area BE. Without it the dynamic rules
   and contract watch show "unavailable" until you add it.
4. **Home Assistant Companion app** on your phone, for alerts.

## Install

1. Settings → Apps (Add-ons) → store → ⋮ → **Repositories**, add this repository's
   GitHub link.
2. Open **Battery Playbook** → **Install**. The Pi builds it locally; this takes a few
   minutes the first time.
3. **Configuration** tab: check the settings (below), **Save**.
4. **Info** tab → **Start**, then open the **Log** tab.

The log lists every entity it found and how. If a required entity is missing or
several candidates match, it stops without changing anything and tells you which
setting to fill in (Configuration → *Show unused optional configuration options*).

When it succeeds it restarts Home Assistant. Then:

1. Do the inverter test from the setup guide (charge for one hour at 10 A, then back
   to self-use).
2. Switch on **Peak shaving enabled** under Settings → Devices & services → Helpers.
3. Set **Fixed price ends on** and **Current contract** (contract watch helpers).

## Settings

| Setting | Default | Meaning |
| --- | --- | --- |
| Install peak shaving / dynamic-tariff rules / contract watch | on | Which packages to write. The other two need peak shaving. |
| Time-of-use slot entities | time_charging | Which Solis slot entities to drive. Switch to grid_time_of_use if the charge test does nothing. |
| Grid import limit | 2.3 kW | Highest grid import while charging from the grid |
| Night target safety margin | 30% | Extra charge on top of the calculated need |
| Night tariff start / end | 22:00 / 07:00 | Your weekday night tariff hours |
| Grid fees and taxes | 11.96 c/kWh | From your bill; update every January |
| Capacity tariff | 52.37 €/kW/yr | Fluvius Antwerpen 2026 |
| Fixed day / night rate | 18.59 / 15.22 c/kWh | First start of contract watch only; later edit the helpers |
| Add the packages line | on | Adds `packages: !include_dir_named packages` to configuration.yaml if missing |
| Restart Home Assistant | on | Only when a file changed and the check passed |
| Remove everything | off | Uninstalls the packages on the next Start |
| Entity settings | empty | Leave empty to detect automatically; fill one in to override |

## What it touches

- Writes `battery_playbook_*.yaml` in your packages folder. Each starts with a
  "Generated by the Battery Playbook app" line; don't edit them, because the next
  Start overwrites them.
- May add one line to `configuration.yaml`, and undoes it if the check fails.
- Stops without writing if it finds your own copies of these packages (for example
  `peak_shaving.yaml` uploaded by hand). Delete or rename those first.
- Keeps the previous version of each file it changed in the app's own storage.

If Home Assistant rejects the new configuration, every change from that run is
undone and the errors are in the log.

## Update

When an update shows up: **Update**, then **Start**. Your settings are kept.

## Remove

Turn on **Remove everything this app wrote**, **Save**, **Start**. Then uninstall the
app. The packages line in configuration.yaml stays; it does no harm.

## Emergency stop

Switch off **Peak shaving enabled** (and **Dynamic tariff control** once you're on
dynamic). The inverter returns to self-use within seconds. Stopping or uninstalling
the app does not stop the automations: they live in Home Assistant.
